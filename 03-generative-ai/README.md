# 03 Generative AI: Assistente Conversacional

Grupo de até 3 integrantes, com nome completo e RM em todos os materiais.

## Checklist
- [ ] Corpus identificável: fontes, URLs, datas de consulta
- [ ] Chunking justificado (tamanho, overlap, metadados), comparando configurações
- [ ] Retriever justificado (BM25, denso ou híbrido; embeddings, top-k, filtros, reranking)
- [ ] Generator justificado (LLM, prompt, parâmetros, citação de fontes, abstenção)
- [ ] Pipeline funcional integrado ao protótipo
- [ ] Mínimo de 10 perguntas: respondíveis, sem resposta, ambíguas, desvio de propósito
- [ ] Avaliação separada: recuperação, geração (contexto controlado), sistema completo
- [ ] Proteção contra resposta não sustentada
- [ ] 2+ testes adversariais (prompt injection, vazamento de prompt ou dados)
- [ ] Sem credenciais nem dados pessoais expostos
- [ ] Relatório: perguntas, evidências recuperadas, respostas, métricas, análise crítica
- [ ] Vídeo de até 5 min com sucessos, falhas, mitigação e limites
