# 07 Cluster Computing (iSPD)

Relatório curto de 2 a 4 páginas, com nome do projeto e integrantes.

## Checklist
- [ ] Tarefa repetida do sistema justificada (ex.: classificar imagens em lote)
- [ ] Número de tarefas, tamanho computacional e comunicação declarados (valores estimados permitidos)
- [ ] Cenário 1: 2 workers. Cenário 2: 4 workers
- [ ] Mesma carga, capacidade, escalonador, banda e latência nos dois
- [ ] Total Simulated Time (s) e uso dos workers (aba Resources)
- [ ] Tabela comparativa com unidades e capturas legíveis
- [ ] Redução percentual e razão T2/T4
- [ ] Discussão de ganho (ou falta), gargalos e limites
- [ ] Arquivos do iSPD ou capturas suficientes para reproduzir
