# 06 RPA e IA

## Checklist
- [ ] Robô de ponta a ponta com ponto de entrada claro (script ou notebook)
- [ ] Pelo menos 3 temas da disciplina, cada um com função real no fluxo (quadro de temas)
- [ ] IA usada onde agrega (modelo de ML, NLP, regras ou LLM opcional)
- [ ] Falhas previsíveis tratadas com log e caminho seguro
- [ ] Sem dados pessoais reais nem chaves no repositório
- [ ] README: integrantes, problema, execução, chaves, temas
- [ ] Evidências: dados de teste, resultado medido em amostra, 1+ falha tratada
- [ ] Diferenciais: timeout, retry com espera, idempotência, relatório de execução, revisão humana
- [ ] Parágrafo sobre proteção de dados, ética e ODS
