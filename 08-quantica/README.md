# 08 Computação Quântica

Sem código quântico. O foco é o raciocínio.

**Entregável:** [relatorio/relatorio_quantica.pdf](relatorio/relatorio_quantica.pdf)
(fonte em [relatorio_quantica.md](relatorio/relatorio_quantica.md); o PDF é gerado por `relatorio/gerar_pdf.py`).

Em uma frase: o gargalo que surge quando o EloBairro cresce é **despachar as equipes de campo** (roteamento com
janelas de tempo, problema combinatório); escolhemos **otimização** quântica para ele, mas só com pilotos e
critérios objetivos, porque hoje os métodos clássicos ganham. A **criptografia pós-quântica** entra como trilha
obrigatória e com prazo, independente de haver computador quântico.
